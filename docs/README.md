# LumaPath documentation

LumaPath is a native iPhone accessibility research project for people with low vision, with an optional Apple Watch companion.

## Explore the app

- [Interface previews](demos/README.md): camera tools, Find, interaction styles, and the Watch companion.
- [Native simulator captures](screenshots/): the implemented interface, including unavailable states.
- [Privacy](PRIVACY.md): local processing, saved data, permissions, and research exports.
- [Validation and limitations](VALIDATION.md): software checks, current evidence, and open physical testing.
