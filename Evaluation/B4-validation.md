# B4 profiles, exercises and quality presentation

Owner: Aarav. Baseline: `26b34e7` (includes Yajat's completed A4 producer). Profile schema 2, defaults 1, quality configuration 2. Software implementation and hosted checks delivered; physical/human G2 and M3 acceptance remain pending.

The Personalization product stores one UUID-named JSON per profile, with atomic protected iOS writes, explicit Save changes, a separately persisted active selection, bounded record reads and per-record error recovery. Schema 1 exposure/contrast records migrate in memory; explicit Save writes schema 2. Unknown versions and damaged records are preserved and cannot be overwritten by this version. No previous released profile format existed; the schema 1 compatibility fixture is documented development input, not a claim of deployed users. Preferences and completion statuses stay local; images and answers are not stored. Reset preserves identity/name and does not touch other profiles, places or reports.

All specification preference fields have controls and per-field manual/exerciseSuggested/preset provenance. Supported live rendering uses exposure, contrast, highlight compression, edges, outline color/width/backing, prioritized density and focus presentation. A saved profile is frozen on entry to Live view. Changing temporary enhancement no longer clears the sensing/event pipeline; Original bypass remains available. Profile changes never introduce detector thresholds or filter acknowledged hazard events. All current event text remains in the accessible summary, even when visible outlines are limited. Ordinary Research activation remains opt-in and independent of the saved phone channel preferences. Spatial/mobility/anticipation/lighting preferences are persisted for B5/B8 integration; no spatial/route behavior is claimed here. Optional speech detail is previewed; the optional description interval is wired to B3's description-only limiter.

Exercises use deterministic supplied bright-window, dim and cluttered calibration scenes (384×256); three contrast levels appear as pairs in shuffled order. Highlight, outline (all three scenes must be checked), placement and five cue meanings support repeat/reset/skip. Suggestions require explicit acceptance into the draft and then explicit Save. Skipped differs from completed. Cue meanings can be repeated or tried as a spoken alternative; new custom haptic pattern families are deferred to physical pattern evaluation. There is no acuity/diagnostic score. Background/disappearance stops cue playback; return does not resume it.

A4's current quality drives readable limitations, regional coverage/confidence, original-image darkness/clipping/contrast, sample age, tracking and threshold-version details. Missing data stays unknown. The UI uses vertical reflow, semantic labels, 56-point main controls, fixed reachable Save/Skip actions, no animated preference transitions and no forced VoiceOver announcements. Reduced highlights selects a dark Live view theme. VoiceOver/Switch Control, Bold Text, increased contrast, Reduce Motion system testing and cue comprehension still require manual device validation.
