# Evaluation evidence

This directory contains synthetic fixtures, historical software-check records, and explicit pending acceptance inventories used by the research and release-audit tools.

- `feature-status.json` and `scenarios.csv` track requirements and acceptance state.
- `Compatibility/` separates injected/simulator evidence from uncompleted physical-device trials.
- `Fusion/` and `Laya/` contain labeled synthetic smoke experiments, not real-world effectiveness results.
- `Studies/` contains the paired-study protocol and an empty physical-trial manifest.
- `Community/` and `Routing/` contain synthetic schema examples.

Historical technical notes retain their original scope. See [the public validation guide](../docs/VALIDATION.md) for current reproduction commands and open limitations. The records are technical evidence for review and reproducibility, rather than product demonstrations.
